# 哔哩哔哩网站动态页：精准时间显示与视频书签跳转

在[哔哩哔哩动态的视频投稿页](https://t.bilibili.com/?tab=video)补充秒级投稿时间，给视频留下阅读书签，刷新或重开后继续看；也可以直接选择最近十天内的日期和时间，返回附近视频。

## 功能

- 保留原有相对时间，在后面追加北京时间，例如“昨天 · 投稿了视频 · 11月12日 20:08:35”；跨年显示年份。
- 时间对应**当前动态投稿时间**，不从“昨天”推算，不替换成转发原视频的时间。
- 在视频卡片右上角三点菜单中增加“标记此视频”，支持多个标记与重复标记去重。
- 在热搜所在右侧列下方增加独立的“视频标记”模块，与热搜模块分开。
- 保留热搜原生吸顶、样式及位置；“视频标记”在热搜下方独立吸顶，标记较多时可在列表内滚动。
- 展示视频标题、作者、精确投稿时间，支持单条删除、勾选多条和全选删除。
- 点击“回到视频”，多个标记时先选择目标；也可以直接点击某条标记的“返回视频”。
- 不需要提前标记，直接在模块内选择最近10天内的日期、小时和分钟，点击“回到该时间”定位到附近视频。
- 通过动态唯一标识定位，目标尚未加载时让网页继续分页加载，并显示追加批次、已加载到的时间和等待状态。
- 原动态不在已覆盖的时间范围内时，定位到附近时间最接近的可见视频，弹窗说明并保留原标记。
- 标记按登录账号分别保存在油猴存储中，刷新、重新打开浏览器后仍可读取。

## 安装

1. 在谷歌浏览器中安装并启用官方 Tampermonkey（油猴）扩展；如已经安装，无需重复安装。
2. 点击上方“安装／更新脚本”，在油猴安装页核对名称和版本后安装。
3. 如果链接只显示代码，可在油猴中添加新脚本，删除默认示例后粘贴完整内容；也可以从[最新版发布页](https://github.com/SiH-zh/bilibili-dynamic-bookmarks/releases/latest)下载`.user.js`（油猴脚本文件）。
4. 刷新需要使用脚本的[动态视频投稿页](https://t.bilibili.com/?tab=video)。
5. 确认视频时间后出现具体时间，右侧热搜下方出现“视频标记”。如果脚本没有运行，请先检查油猴是否启用、站点访问权限和浏览器对用户脚本的运行设置，参考[油猴官方文档](https://www.tampermonkey.net/documentation.php?locale=zh_CN)。

安装后的脚本会作用于所有符合地址条件的视频投稿页，不识别或限制浏览器标签组。运行本脚本不需要安装开发工具。

### 从旧版升级

**0.1.0至1.1.0的用户，请在油猴中编辑原来的脚本，将全部代码替换为最新版后保存，再刷新动态页。** 不要先卸载或清空旧脚本数据。

本次公开发布更改了脚本中文名称。在原条目里编辑可以沿用原存储；如果直接另建新名称的脚本条目，书签存储可能分开。命名空间、存储键和数据格式没有改变。

1.1.1开始配置了自动更新地址。此前版本需要先手动替换一次，之后即可使用油猴的更新检查。

### 后续自动更新

脚本的`@updateURL`（更新检查地址）与`@downloadURL`（完整脚本下载地址）均指向本仓库主分支的原始脚本。油猴检查到更高版本后，按扩展的更新设置获取新版本，也可以在油猴中手动检查更新。联网访问更新地址成功是获取更新的前提。

每次正式更新都会递增版本号并写入[更新记录](CHANGELOG.md)。更新由油猴完成，不会向仓库上传本地书签。

## 使用

### 添加标记

打开视频卡片右上角的三点菜单，选择“标记此视频”。同一条动态只保存一次，不影响哔哩哔哩的收藏、稍后再看、点赞或关注。

### 返回视频

点击独立模块中的“回到视频”。只有一个标记时直接定位；多个标记时先选择一个。点击某条标记下的“返回视频”则直接定位该条。

定位时会显示“正在加载视频”“已加载至：2026年11月12日 20:08:35”等提示。其中“已加载至”是当前已读取视频数据中的最早投稿时间，少量乱序内容可能影响这个时间，它并非百分比进度。网页响应较慢时显示等待秒数，点击“停止定位”即可停止后续加载。已经发出的网页请求可能仍会正常完成。

脚本调用网页现有的分页加载方法，加载过程中主要更新进度，找到目标后再滚动并高亮视频，不要求用户手动滚到底部。相邻批次之间至少等待约一秒，单次最多追加 500 批；达到上限后可以再次点击继续从已有列表查找。

### 原动态不见了

脚本以动态唯一标识确认目标，而不是仅比较时间或滚动高度。加载尾部到达标记时间之前、覆盖目标时间两侧后，会再尝试读取一批，减少边界和少量乱序的影响。

仍找不到目标时，选择**当前已加载范围内**投稿时间最接近、且页面可见的视频，时间差相同时优先较早投稿的视频。弹窗提醒原动态可能已失效、被删除或从当前列表消失，需要自行确认。原标记不会被附近视频覆盖。

网络错误、加载超时、历史提前结束或其他脚本过滤内容时，会报告查找中断或目标不可见，不会直接断定视频已删除。动态列表并非严格的完整历史档案，附近定位也不证明原视频已经删除。

### 按日期时间返回

在“视频标记”模块中找到“选择时间（北京时间）”，选择日期、小时和分钟，再点击“回到该时间”。不需要先创建标记，也不会自动新增标记。

可选范围为点击查找时从当前时刻向前 **240 小时，即最近10天**，不能选择未来时间。日期时间选择器按分钟输入，范围边界对齐到可选的完整分钟；换算固定使用北京时间，不受操作系统时区影响。

脚本在当前动态列表的可用内容中查找投稿时间最接近的视频，必要时继续分页；定位后展示视频实际时间、标题及与所选时间的分钟差。时间差相同优先选择较早投稿的视频。按时间查找不会弹出“原标记失效”的提醒，也不会创建新标记。

为限制持续加载，按时间查找单次最多追加 **100 批**，达到约 **4000 条已加载动态**或运行 **2 分钟**后停止追加；也可以随时点击“停止定位”。触及上限但尚未覆盖目标时间时会报告查找未完成，不会假装定位成功。原有的按标记返回不受新增十天范围限制。

这些限制控制脚本的查询范围和追加加载，**不等同于浏览器内存用量的硬上限**。已加载的网页内容不会被强制删除，正在进行的一批请求可能使数量略超阈值。到达十天边界后不再主动追加更早批次，但单批网站响应可能包含边界以外的尾部内容，候选视频只从十天以内选择。

### 管理标记

可以逐条删除，或勾选多条后点击“删除所选”；“全选”选中当前账号全部标记。删除不会删除网站上的视频或动态。当前版本尚未提供撤销、导入、导出或跨设备同步功能。

## 数据与权限

脚本只读取当前页面已有的动态信息和账号编号，不读取密码、验证码或登录凭据，不上传标记，不加载第三方运行时依赖。标记包括动态编号、投稿时间、标题、作者、可取得的视频编号和添加标记的时间。

权限用于读取网页数据，以及读写、监听油猴的本地标记存储。卸载油猴、删除脚本及其数据或清理扩展数据可能导致标记丢失。普通刷新、关闭标签页或重启浏览器不会主动清空标记。多个标签页监听同一账号的标记变更；极短时间内同时写入仍可能受到油猴存储缺乏事务机制的限制。

## 兼容性与限制

- 目标环境为桌面谷歌浏览器与油猴；其他浏览器、脚本管理器尚未验证。
- 仅在根路径且地址参数 `tab=video` 的视频投稿页启用；文字、专栏、视频播放页不启用功能。
- 依赖哔哩哔哩网页的现有组件数据和菜单结构，网页改版可能需要适配。
- 不依赖每条卡片都带有 `data-did` 属性；缺少该属性时从卡片组件读取动态编号。
- 其他动态过滤、屏蔽或页面美化脚本可能隐藏卡片、菜单或右侧栏，需要结合实际环境排查。
- 很久以前的标记需要逐批加载，无法保证瞬间到达，也无法获取网站不再提供的历史内容。
- 没有可确认的秒级时间时，不会用相对时间补造秒数。

## 本地开发与自动检查

需要 Node.js（JavaScript 运行环境）24.15.0 或更高版本。用户安装油猴脚本时无需安装此开发环境。

```sh
npm ci --ignore-scripts
npm run check
npm test
```

脚本本身是单文件，无构建步骤和外部运行时依赖。开发依赖 jsdom（页面模拟库）只用于本地测试。根目录脚本是发布文件，避免多份源代码与发布文件版本不一致。推送与合并请求会运行[自动检查](https://github.com/SiH-zh/bilibili-dynamic-bookmarks/actions/workflows/check.yml)，覆盖语法、版本、名称、更新地址与39项功能测试。
