本地检查结果：语法与版本一致性检查通过，**24 项自动化测试全部通过**。版本一致性检查同时覆盖脚本头、界面版本、项目配置和依赖锁文件。

## 已完成

- 只读获取动态页当前公开前端代码，确认动态时间组件、视频卡片、原生分页方法及分页结束和错误状态。

- 本地自动化测试覆盖北京时间秒数、跨年、当前动态时间、编号字符串精度、标记去重、批量删除、数据损坏保护、同秒不同编号、乱序时间判断和最近时间选择。

## 首次安装验收清单

- [ ] 在专用测试动态页安装并刷新，检查精确时间与右侧独立模块。
- [ ] 对比两条动态的后台时间数据，确认秒数与北京时间换算。
- [ ] 展开卡片三点菜单，添加两个标记，检查标题、作者、时间和重复标记去重。
- [ ] 点击“回到视频”，检查多标记选择窗口及单条直接返回。
- [ ] 刷新、关闭后重新打开，检查标记仍在。
- [ ] 标记较后方视频，刷新后定位，检查逐批加载、进度和最终高亮。
- [ ] 模拟缺失目标，检查附近候选和提醒，确认原标记保留。
- [ ] 定位中停止，检查不再触发后续加载和失效提醒。
- [ ] 检查勾选多条、全选和删除所选。
- [ ] 如同时使用动态过滤脚本，检查目标被隐藏时不会被误判为确定删除。
